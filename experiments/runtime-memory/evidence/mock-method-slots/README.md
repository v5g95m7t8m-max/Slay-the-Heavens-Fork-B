## Reproduce

All outputs into fresh scratch; baseline repo and original fixture remain
unchanged for cold-construction runs.
```sh
root=/path/to/exact-develop-worktree  # npm ci done, approved LFS inputs hydrated
exp=/path/to/this/evidence
out=$(mktemp -d)
orig="$out/original.lua"
cp "$root/tests/lua/support/game_ui_fixture.lua" "$orig"
cp "$orig" "$out/inherited.lua"
mkdir -p "$out/patch/tests/lua/support"
cp "$orig" "$out/patch/tests/lua/support/game_ui_fixture.lua"
(cd "$out/patch" && git apply "$exp/inherited-methods.patch")
cp "$out/patch/tests/lua/support/game_ui_fixture.lua" "$out/inherited.lua"
SOAK_PREPARE_ONLY=1 ABYSS_PYTHON=python3 node "$exp/soak.mjs" "$root" "$out/prepared" host-settled 2
for arm in original inherited inherited original; do
  node --max-old-space-size=768 --expose-gc "$exp/control-micro.mjs" "$root" "$out/prepared/generated" "$out/$arm.lua"
done
```

The full behavioral A/B used two fresh processes sequentially, fixed
`NODE_OPTIONS=--max-old-space-size=768`, the same prepared generated files
outside measurement, same seed 2 and original `host-settled` workload,
no explicit GC, and only swaps the fixture variant in the isolated scratch
worktree. It cannot be an A/B against the earlier GitHub hard-cap run.

## Full one-VM result (one matched local pair, n=1 per arm)

Uncapped local-only; both fresh V8 processes used the same existing 768 MiB
old-space setting, identical generated files/driver (all SHA receipts match),
and ran the original `host-settled` seed 2 plan. No forced GC or workload
changes. Both passed all 34 rooms, victory, and new Neow, with 1,090 exact
action lines, 37 state checkpoints, and the result byte-identical to one
another **and** the earlier hosted control. Only Node version (local 24.22.3
vs hosted 24.19.0) differs in driver/fixture identity; the environments and
actual enforced limits are not the same.

**Decision:** ~40.9 MiB of separable cold *retained V8 allocation* in the mock
is demonstrated; the complete one-pair *process peak* differed only 3.2 MiB.
The restart sample gap and elapsed difference do not establish stable memory
savings, nor safe performance, given one pair and uncontrolled host load.
This is **not a production fix or a new peak-memory result for the 1 GiB
lane**. Do not subtract the cold component from the 812 MiB cgroup receipt.
Keep the existing fixture unless its contract is intentionally reworked
and independently approved. If peak causality still matters, repeat
counterbalanced A/B in the exact hosted lane at already-approved resource
limits, without modifying assertions or publishing a new release gate.

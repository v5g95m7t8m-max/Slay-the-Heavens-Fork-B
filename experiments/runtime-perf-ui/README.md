# 战斗手牌文字拟合 A/B（隔离诊断）
 
基线：`32a15219aecd145c59cb1b2fcf477e5556766e5d`。只测现有 `official-assets-first` 生成布局与仓库 Host 转接；没有运行旧版 SDK `vi`、官方 GIL 或千星客户端，不能把历史 132–144 ms 与本轮绝对时间直接比较。
 
## 发现与改动
 
- 当前实测输入链：点选卡面 → 目标 Down 构造瞄准预览并完整刷新一次 → Up/Click 两次完整刷新（命令前的失败保护、规则提交后的首帧）。历史观察还包括成功出牌后的冗余尾部刷新；当前已有 `feedbackPresented`，正常路径不再执行这次尾刷。不能删命令前渲染，其失败会阻止规则提交。
- 手牌标题/正文每次重新计算行宽和行数，已有牌组浏览场景使用相同且有上限的 `CardDisplay.newTextFitter()`。B 在战斗卡面所有者中复用它，缓存纯拟合结果（相同字符串与字号、宽高、缩放等）。不缓存实际控件或跳过任何写入，最多存 128 个、不记录超过 1024 字节的文本，与现有浏览器限制相同。
 
## 结果
 
8 个新进程配对区组，按 AB/BA 交错、固定同一 CPU。每组每臂 3 次点选、目标 Down、Up+Click 和反馈结算；120 个稳态 Update。以下为基线 A→B，近秩 P95。
 
| 阶段 | CPU P50 / P95 / max (ms) | 墙钟 P50 / P95 / max (ms) |
| --- | --- | --- |
| 稳态 Update（960/臂） | 0.267 / 0.442 / 9.289 → 0.254 / 0.407 / 1.377 | 0.273 / 4.358 / 17.318 → 0.261 / 3.877 / 16.429 |
| 点选（24/臂） | 3.350 / 4.942 / 5.479 → 2.649 / 3.869 / 5.127 | 7.457 / 13.242 / 15.249 → 6.547 / 11.515 / 15.256 |
| 敌目标 Down | 3.019 / 4.179 / 4.413 → 2.171 / 3.960 / 4.553 | 7.041 / 13.637 / 15.088 → 6.019 / 12.173 / 15.180 |
| 出牌提交 Up+Click | 23.637 / 30.148 / 48.753 → 18.839 / 28.131 / 30.450 | 48.431 / 73.908 / 95.911 → 40.190 / 81.949 / 92.113 |
| 反馈后续结算 | 14.158 / 21.362 / 32.771 → 12.578 / 17.246 / 20.234 | 30.716 / 64.595 / 67.524 → 25.497 / 43.915 / 44.137 |
 
- 出牌 CPU 区组配对中位差 −1.421 ms，8 组中 5 组改善；墙钟配对中位差 −5.568 ms，5/8 改善，但合并样本墙钟 P95 反而上升，不能称长尾改善。
- 独立计数三次出牌中，完整文字拟合 102→0；预览 54→0。原生替身方法调用和字段写入完全一致（三次出牌 14,527 / 18,355），两侧控件都为 25,830 个离线控件。两侧首屏及连续三次操作后的文本、字体字号、可见性和规则结果指纹完全相同。另一条负控在命令前故意让 render 抛错；两侧都没扣 HP、没扣能量、未增事件、未用牌且恢复可操作。
- 进程 RSS 峰值 P50 111,108→108,056 KiB（8 次，P95 即最大值：112,156→108,084 KiB），只代表 LuaTeX Host；stage 后 `collectgarbage('count')` 是 Lua 堆采样，不是 GC 暂停或器件内存证据。没有新增 GIL 体积/官方层级或 GPU 数据。
 
**NO-GO 集成**：明确去掉 Lua 纯计算，但没有可靠墙钟尾部收益；先保留隔离补丁。下一步可用正式设备同档重测，再决定是否启用。减少原生调用或整次刷新是另一切片，要保留失败保护和所有前后状态。
 
## 复现
 
1. 在上述干净提交准备 `git lfs pull`、`npm ci`；保持真实资源，不使用 LFS 指针替代。
2. 在仓库根生成同一布局：
 
   ```sh
   node --input-type=module - <<'NODE'
   import {buildLuaData} from './scripts/build-lua-data.mjs';
   import {buildUI} from './scripts/build-ui.mjs';
   buildLuaData();
   buildUI('build/lua', undefined, {officialAssets:true});
   NODE
   ```
 
3. Linux 安装 LuaTeX（采样使用 1.18.0）、Python 3、taskset 和 patch。在相同本地 CPU 配额上运行 `STH_UI_CPU=7 python3 experiments/runtime-perf-ui/run-ab.py`，CPU 不存在时显式指定可用编号。B 变体只生成到临时文件，不改源码。输出 `build/hand-text-fit-ab.json`，或指定 `STH_UI_REPORT`。CPU 用 Lua `os.clock`，墙钟用 LuaTeX `os.gettimeofday`；计数另测，不混算进时延。

候选另跑原 `official-assets-runtime.test.mjs` 五条：成功出牌与失败保护、十牌双敌取消/拖放/回合、Weak/Vulnerable 目标数值、全牌排版、溢出详情。全部通过，0 跳过。完整输出见 `directed-tests.log`。

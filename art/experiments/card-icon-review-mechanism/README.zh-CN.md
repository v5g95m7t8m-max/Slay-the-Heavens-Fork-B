# 卡牌图标制作与独审机制 v0.1

不把“像原神”当成一句提示词。不预设一定要对称、无框、无人物或只能画硬边。每轮把实际原图、设计修订和盲评结果一起留档。

1. **先核牌效**：一张牌只规定一个必须看懂的主体或动作，以及最容易认错的近邻。数值或机制细节由文字负责，不把没必要的信息画成符号。
2. **按题找参照**：至少从两类实际原版图标取具体做法，记录角色、技能名、原图、借的是哪个结构。盾用诺艾尔的切面研究，岩墙研究岩主与钟离的体量和地脚，势能或动作看刻晴、行秋、夜兰的收笔；不是把它们的材质一锅混合。纳西妲的取景框是动作，胡桃的蝶对称是主体，不能照着给所有牌套框或反过来禁用对称。图库可用 ID 与游戏提取参考图分开登记。
3. **交一版可测的透明稿**：固定文件版本与画幅。先看大轮廓，再用该动作确实需要的线、负形、遮挡或接触点；没帮助辨认就删，与卡框和底色分层。
4. **先盲读再评风格**：144×64、统一灰底、无牌名、随机顺序。两位非制作者先独立说看到什么、在做什么、把握多大。答案锁定后才揭晓牌效，再对照原图和本作同框效果复审。两个结论都支持必需读法才过；如果出现实质分歧，记录哪一处误读，一轮只改一个控制点。重测不是假装上一轮通过，也不为追求一致而筛掉反对票。换一位没有看过前版的人可减少先入为主。
5. **先过小样，再扩产**：一类至少留一张能过审的标准样。图元拟合、低中高对照、千星真机是后续独立关。图标轮廓错就改设计，不靠增图元修正。75 张旧稿不因小样通过自动放行。

建议每张牌保留的记录：稳定 ID、牌效、视觉主动作、容易混淆的形状、两个参照及各自用途、透明源稿哈希、两份原始盲读、复审决定、修改变量、同框图、拟合/实机状态。

## 本次实测例子
- 防御：双圈盾与单个盾面都有人能认出。新稿价值不在答案更明显，而在受击线与盾的接点更明确、更像原图的动作结构。
- 永世的磐岩：三尖旧稿有人读作王冠。新版逐步从岩块改成同一条地基上的横向岩垒。要求图像与单盾区分；“保留格挡”由牌文说明。
- 星陨剑：先读成斜划、后读成向上喷石或下落。对照只改尾迹与地线，直到主要动作清楚。仍需如实保留边缘歧义。

本次两组共核过 13 位角色、19 张不重复的原版技能图标。经过 5 轮小样，末轮另找了两位没看过这批图的评审，均首读为「岩垒／落岩击地／单面挡击」。仍有次要歧义：岩垒可能像一簇石块，星陨剑尾迹略像火光，防御未必会明确认作岩质。这三张只够作机制小样，不代表每处造型已定稿。现有机制和盲评记录可用于下一轮。
